# Contributing

Contributions are accepted under `GPL-3.0-or-later`.

Useful issue reports and LLM-assisted pull requests with tests, reasoning, and
clear review notes are preferred. Hand-writing code is welcome for trivial
changes, careful design work, or pure enjoyment, but it should not be treated as
a moral requirement.

See [docs/contributing.md](docs/contributing.md) for the full policy.
